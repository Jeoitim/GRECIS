# GRECIS 考研外刊词汇红宝书

领域语料库驱动的考研英语阅读词汇与表达

## 使用说明

- 本红宝书词汇量大、内容丰富，已按**学科专业板块**拆分为多个子文件，方便日常背诵与阅读。
- 先背各板块的熟词生义和固定搭配，再看领域术语。
- 每个词条优先记“考研义”和“误译风险”，不要只背中文对照。
- 例句分为项目例句 and 语料库例句；语料库例句来自本地已抓取文章的短摘录。

## 快速背诵清单

| 词条 | 领域 | 核心义 | 先记风险 |
| --- | --- | --- | --- |
| issue | 政治法律 | 争议焦点；议题；发布；发行 | 只译成“问题”会错过作者真正讨论的争议核心。 |
| at issue | 政治法律 | 争议焦点在于 | 不要逐字译为“在问题上”。 |
| take issue with | 政治法律 | 反对；质疑；提出异议 | 漏掉 with 后面的观点对象，会误判态度。 |
| hold | 政治法律 | 裁定；认为；持有 | 译成“法院持有”会完全错读。 |
| find | 政治法律 | 裁定；认定；研究发现 | The judge found that... 不是“法官找到了……” |
| case | 政治法律 | 案件；论据；情形 | make the case for 不是“制造案例”，而是“论证支持”。 |
| acquisition | 经贸金融 | 收购；取得 | 与 merger 不同，acquisition 强调一方取得控制权。 |
| merger | 经贸金融 | 合并；并购中的合并 | 不要和 acquisition 完全等同。 |
| capital | 经贸金融 | 资本；资金；大写的；首都 | 人力资本 human capital 是教育经济类高频概念。 |
| yield | 经贸金融 | 收益率；产生；让步 | bond yield 不是“债券产出”。 |
| regulation | 经贸金融 | 监管；法规 | 不要只译成“调节”。 |
| emissions | 环境气候 | 排放物；排放量 | carbon emissions 是“碳排放”，不是“碳发射”。 |
| mitigation | 环境气候 | 缓解；减缓 | 与 adaptation 区分：mitigation 减缓变化，adaptation 适应影响。 |
| adaptation | 环境气候 | 适应；改编 | 不要与 mitigation 混同。 |
| school | 教育社会心理 | 学校；学派 | 看到 economists from one school 不一定指同一学校。 |
| position | 教育社会心理 | 立场；观点；位置 | 不要把 position 全部译成物理位置。 |
| concern | 教育社会心理 | 担忧；涉及；企业 | a going concern 是会计语境中的“持续经营企业”。 |
| subject | 教育社会心理 | 主题；受试者；受制于；使遭受 | subject to change 是“可能变动”。 |
| drive | 教育社会心理 | 驱动；推动；驱动力；驾驶 | 不要把 drive in prices 误解成“开车进入价格”。 |
| move | 教育社会心理 | 举措；行动；移动 | 新闻中名词 move 常是政策或商业动作。 |
| suggest | 研究方法与学术论证 | 表明；暗示；建议 | The findings suggest... 不是“发现建议……”。 |
| significant | 研究方法与学术论证 | 统计显著的；重要的 | significant difference 常是统计术语。 |
| account for | 研究方法与学术论证 | 解释；占比 | 要根据宾语判断是“解释”还是“占比”。 |
